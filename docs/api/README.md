# API Documentation

## Endpoints

### Relay
- `POST /{topic}` - Publish sealed frame
- `GET /{topic}/json` - Subscribe (SSE)
- `GET /healthz` - Health check
- `GET /probe` - Probe endpoint

### Gaze
- `GET /` - Dashboard
- `GET /world` - World map
- `GET /healthz` - Health check

### World
- `GET /` - Dashboard
- `GET /healthz` - Health check
